# MyWeather

Interactive weather app (frontend only): splash, bypass login, home, forecast, alerts, locations with chatbot, and sea waves with a Philippines map.

## Run locally
Open `index.html` in a browser, or in VS Code install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.

## Push to GitHub
```bash
git init
git add .
git commit -m "MyWeather web app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/myweather.git
git push -u origin main
```

## Deploy on Vercel
Import the repo at vercel.com/new. Framework preset: Other. No build command needed.
